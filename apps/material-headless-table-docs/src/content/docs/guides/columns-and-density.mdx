## Show and hide columns

The columns button in the toolbar lists every column. Start with some hidden using
`initialState={{ hiddenColumns: ['email'] }}`; `enableHiding: false` on a column keeps it visible, and
`enableColumnVisibility={false}` removes the button.

## Resizing

`enableColumnResizing` lets users drag the edge of a header, and double click it to reset. Start widths come from
`width`, limited by `minWidth` and `maxWidth`. `enableResizing: false` on a column pins its width.

## Density

The density button cycles `comfortable`, `compact` and `spacious`. Start with one using
`initialState={{ density: 'compact' }}`, or remove the button with `enableDensityToggle={false}`.

`striped` adds zebra rows.
