Every string the table shows (buttons, tooltips, menu items, placeholders, aria labels) comes from the `localization`
option. The default is English.

## Using a built in locale

Each locale is its own module, so only the ones you import end up in your bundle:

```svelte
<script lang="ts">
  import { ShadcnSvelteTable } from 'shadcn-svelte-tanstack-table';
  import { MRT_Localization_FR } from 'shadcn-svelte-tanstack-table/locales/fr';
</script>

<ShadcnSvelteTable options={{ columns, data, localization: MRT_Localization_FR }} />
```

## Overriding or adding strings

`localization` takes a partial object, and anything you leave out falls back to English. Spread a locale to change a
few of its strings:

```ts
import { MRT_Localization_DE } from 'shadcn-svelte-tanstack-table/locales/de';

localization: { ...MRT_Localization_DE, search: 'Suchen…', noRecordsToDisplay: 'Keine Einträge' },
```

Some strings contain placeholders in braces, for example `filterByColumn: 'Filter by {column}'` and `groupByColumn: 'Group by {column}'`. Keep the placeholders in your translation.

## A locale of your own

Type it as `MRT_Localization` and the compiler lists every key you still need:

```ts
import type { MRT_Localization } from 'shadcn-svelte-tanstack-table';

export const MyLocale: MRT_Localization = {
  language: 'xx',
  // ...
};
```

The full list of keys is in the `MRT_Localization` type, and `src/lib/locales/en.ts` in the repository is a complete
example to copy. Contributions of new or corrected locales are welcome.

## Right to left languages

Arabic (`ar`), Persian (`fa`) and Hebrew (`he`) read right to left. Set `dir="rtl"` on a parent element, and
`columnResizeDirection: 'rtl'` if column resizing is enabled.

## Date and time inputs

The date filters use the browser's native date and time inputs, which follow the browser's language rather than the
table's `localization`.
