Create, edit and delete users. Edits go through a dialog, validated in the save handler: returning without calling
`exitEditingMode()` keeps it open. In a real app, replace the local `data` updates with requests.
See the [Editing guide](/guides/editing/).

The Create button is the shadcn-svelte `Button`, which the package re-exports.
