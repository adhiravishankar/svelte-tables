Material Svelte Table needs **Svelte 5**. Everything else it uses (TanStack Table v9, TanStack Virtual and
[Svelte Material UI](https://sveltematerialui.com)) is installed with it.

<Steps>

1. Install the package.

   <Tabs syncKey="pm">
     <TabItem label="npm">
       ```sh
       npm install material-svelte-table
       ```
     </TabItem>
     <TabItem label="pnpm">
       ```sh
       pnpm add material-svelte-table
       ```
     </TabItem>
     <TabItem label="yarn">
       ```sh
       yarn add material-svelte-table
       ```
     </TabItem>
   </Tabs>

2. Import the stylesheet once, for example in your root layout. It contains the base styles of the Svelte
   Material UI components the table is built from.

   ```ts
   import 'material-svelte-table/styles.css';
   ```

3. Define the Material theme variables you want. The table reads these and has sensible fallbacks, so this
   step is optional. See [Theming](/guides/theming/).

   ```css
   :root {
     --mdc-theme-primary: #1976d2;
     --mdc-theme-surface: #ffffff;
     --mdc-theme-on-surface: #000000;
   }
   ```

</Steps>

## SvelteKit and Astro

The package ships `.svelte` files, so a bundler that understands Svelte is needed. SvelteKit, Vite with
`@sveltejs/vite-plugin-svelte`, and Astro with `@astrojs/svelte` all do. In Astro, render the table in an island
with a client directive (this site uses `client:load`).
