Bootstrap Svelte Table needs **Svelte 5** and **Bootstrap 5**. Everything else it uses (TanStack Table v9 and
TanStack Virtual) is installed with it.

<Steps>

1. Install the package.

   <Tabs syncKey="pm">
     <TabItem label="npm">
       ```sh
       npm install bootstrap-svelte-tanstack-table bootstrap
       ```
     </TabItem>
     <TabItem label="pnpm">
       ```sh
       pnpm add bootstrap-svelte-tanstack-table bootstrap
       ```
     </TabItem>
     <TabItem label="yarn">
       ```sh
       yarn add bootstrap-svelte-tanstack-table bootstrap
       ```
     </TabItem>
   </Tabs>

2. Import the stylesheet once, after Bootstrap, in your global CSS. It bridges the library's tokens onto
   Bootstrap's own `--bs-*` CSS variables.

   ```css
   @import 'bootstrap/dist/css/bootstrap.css';
   @import 'bootstrap-svelte-tanstack-table/styles.css';
   ```

3. Optionally, define your own Bootstrap tokens after that import. If your app already has a Bootstrap 5 theme
   (including Bootstrap's own `data-bs-theme="dark"` color mode), the table follows it automatically. See
   [Theming](/guides/theming/).

   ```css
   :root {
     --bs-primary: #7c3aed;
   }
   ```

</Steps>

## SvelteKit and Astro

The package ships `.svelte` files, so a bundler that understands Svelte is needed. SvelteKit, Vite with
`@sveltejs/vite-plugin-svelte`, and Astro with `@astrojs/svelte` all do. In Astro, render the table in an island
with a client directive (this site uses `client:load`).
